# Marina Bay Racer on Sites

The local server remains `npm start` on port 3000. The Sites build preserves
the original Three.js and Rapier assets and changes only the online transport.

## Hosted services

- Same-origin Worker endpoint exchanges WebRTC SDP with OpenAI. The permanent
  key is a Sites secret, never a public file or browser variable.
- Site-provided ChatGPT identity is required for multiplayer and voice. Private
  Site sharing is the outer access control; changing a URL does not grant access.
- Race rooms support eight players, with shared D1 snapshots at up to 5 Hz and
  client interpolation. This is casual prototype multiplayer, not an authoritative
  competitive race server. Cars remain client-simulated; remote cars do not collide.
- Race state expires after inactivity. Only hashed identity keys and positions
  are stored. No voice recordings or transcripts are saved by this application.
- Aunty retains `gpt-realtime-1.5` and `marin`. Session creation is limited to
  3 attempts per signed-in user per UTC day and 12 for the Site. Each ordinary
  client ends its connection after 10 minutes. The client timer is not a security
  boundary or hard monetary cap: configure API-project spending controls before
  broad sharing. Failed attempts consume quota to prevent automatic retry storms.

## Development and deployment

Run `npm run db:generate` after schema changes, inspect the generated migration,
then run the Sites build helper. Use Wrangler only for local preview, never to
provision or deploy production resources. Sites manages DB and deployment.

Required hosted secret: `OPENAI_API_KEY`. Until securely configured, racing,
the Aunty mascot and locally scheduled subtitles work; live voice reports that
setup is pending. Never claim a successful voice test until a real session works.
